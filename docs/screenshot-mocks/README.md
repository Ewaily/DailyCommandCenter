## Tips

- Use Chrome DevTools device toolbar to lock the viewport to the exact dimensions above.
- Zoom to 100% (Cmd+0) before capturing.
- Use a full-page screenshot tool or the DevTools capture button (three-dot → Capture screenshot).
- Save each capture directly to `docs/assets/` with the filename listed above.
- Once all screenshots are saved, send them back and the README placeholder blocks will be replaced with the real `![...]()` image tags.
