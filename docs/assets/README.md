# Visual assets

Screenshots, diagrams, and other binary assets that the markdown docs reference.

Every image needed here — what it should show, where it appears, and how to capture it cleanly — is enumerated in [`../VISUALS_MANIFESTO.md`](../VISUALS_MANIFESTO.md). Treat that file as the spec; this directory is just the destination.

Naming convention: lower-kebab-case, descriptive of content rather than placement (`dashboard-preview.png`, not `readme-hero.png`), so the same image can be reused without breaking the name.
